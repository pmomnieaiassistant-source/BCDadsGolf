# BC Dads Golf: blueprint

Last updated for version 0.5.5.

This describes what the golf scoring app does today, in plain words. It is read by the idea assistant so it can tell when an idea asks for something that already exists, or clashes with how the app works. It is updated every time an idea is built. It does not describe the Build board where members discuss ideas.

## What the app is

A phone-first web app for one small group of friends (the BC dads). Members open it in their phone browser. It opens instantly and updates itself the next time it is opened. It needs an internet connection to load and save anything.

Everyone joins with the group's code (or an invite link from the admin) and picks a display name. There are no emails or passwords. There is one group and one admin (Paul).

The app has two sides, shown as a toggle at the top: Use and Build.

- **Use** is the golf scoring app itself.
- **Build** is where the group posts and discusses ideas for what Use should become. It is not described here. Ideas about the Build board itself are not golf features.

## The Use side today

Nothing has been built on the Use side yet. It shows a short message and a button to the Build side. This means there are currently no courses, no rounds, no scorecards, no scores, no handicaps, no scoring formats (stableford, stroke play or any other), no teams or pairings, no leaderboards, no statistics and no history.

Any idea for one of those is new. If an idea asks for one of them, it is not already there.

## App-wide features that exist

- **How-it-works guide.** When someone opens the app, a short swipeable guide can appear, with a close button and a "Don't show this again" box. Each person's choice is remembered for them.

## Scoring rules

No scoring rules or formats have been decided or built. Golf scoring rules (stableford points, handicap strokes, net and gross scores) have exact right and wrong answers, so a scoring idea has to state its rules precisely before it is ready to build.

## Not built yet

Everything on the Use side.
